## Talk descriptions
- Beyond the Scan: Finding the last 70% with manual testing for digital accessibility
Did you know automated tools only catch about 30% of web accessibility issues? In this practical session from the Office for Digital Accessibility (ODA), we’ll break down what digital accessibility testing really takes. We’ll show you how to perform hands-on manual testing, including accessibility insights workflows and using the ODA’s new Digital Accessibility Testing Protocol course, so you can find the last 70% of accessibility barriers and build truly inclusive web experiences. This presentation is intended for people working on websites and are familiar with the 7 core accessibility skills.

- Application Security at the U
